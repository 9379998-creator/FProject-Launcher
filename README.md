# FProject Launcher

**FProject Launcher** — локальное инженерное приложение для каталогизации папок объектов, быстрого рендеринга и интерактивного просмотра проектной документации (PDF, DWG, Office/Excel), а также запуска расчетных модулей.

## Основные возможности

- **Индексация и навигация:** быстрый импорт папок проектов, древовидная структура файлов, фильтрация по форматам (PDF, DWG, Excel и др.).
- **Рендеринг документов:**
  - PDF: миниатюры 72 DPI, обзорные страницы 150 DPI, детальный просмотр 300 DPI с локальным кэшированием.
  - DWG: автономный рендеринг чертежей и пространств листов (Layouts) в высоком разрешении.
  - Excel/Таблицы: предварительный просмотр листов и структурных данных.
- **Интерактивный просмотрщик:** зум, панорамирование, поворот, переключение страниц/листов.
- **Архитектура:** локальный Python API сервер + легковесный Web UI (HTML5/Canvas/CSS).

## Структура проекта

```text
app/
  frontend/      Интерфейс браузера и вьювер (HTML/CSS/JS).
  backend/       Локальный Python API сервер и движки обработки.
  rendering/     Диспетчер рендеринга (PDF, DWG, Office).
  shared/        Общие схемы и константы.
docs/            Архитектурная документация и регламенты.
scripts/         Скрипты сборки и запуска под Windows.
tests/           Автоматические тесты и сценарии проверки.
runtime/         Локальные временные папки (кэш, логи, БД — игнорируются Git).
```

## Быстрый запуск

1. Запустить скрипт `Запуск_Лаунчера.cmd` или `Запуск_Нового_Лаунчера.cmd`.
2. Интерфейс откроется в браузере по адресу `http://localhost:8780`.
