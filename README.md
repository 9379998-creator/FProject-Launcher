# Fero-Launcher

> **Бренд и лейбл**: FERO / Fero Engineering  
> **Официальный репозиторий**: [https://github.com/9379998-creator/Fero-Launcher](https://github.com/9379998-creator/Fero-Launcher)  
> **Текущая версия**: 4.5.0 (Production Release)  
> **Дистрибутивы для коллег**: `G:\Общие диски\022_F-Engineering\01_FERO-Launcher`

**Fero-Launcher** — флагманское локальное инженерное приложение продуктовой линейки **FERO** для каталогизации рабочей проектной документации, быстрого рендеринга и интерактивного просмотра чертежей (PDF, DWG, DXF, Office/Excel), сопоставления спецификаций и запуска расчётных модулей.

---

## Продуктовая экосистема FERO

В рамках развития бренда **FERO** формируется единая линейка инженерных и цифровых решений:
- **Fero Engineering** — комплексный инжиниринг, проектирование и экспертиза фасадных оболочек.
- **Fero-Launcher** — настольный диспетчер, многооконный просмотрщик и навигатор по проектным архивам.
- **Специализированные модули Fero** — оценка объёмов (Fero Estimator), теплотехническое моделирование (Fero Thermal), пакетные конвертеры (Fero Doc Converter) и др.

---

## Ключевые возможности Fero-Launcher v4.5.0

- **Многооконный режим (Multi-Window Drawing Comparison):**
  - Одновременное открытие нескольких независимых окон для сравнения планов, разрезов и спецификаций в 1 клик (`Ctrl+N`, кнопка «🗗 В новом окне» или контекстное меню).
  - Единый сервер-демон на каноническом порту `8780` с автоматическим подсчётом активных окон (*reference counting*) и сторожевым таймером (*idle watchdog*).
- **Адаптивное дерево файлов (Adaptive Tree Expansion):**
  - Автоматическое полное раскрытие папок для рабочих комплектов и выборок (до 150 файлов) без слепых стрелок.
  - Каноническая жёлтая иконка каталогов для всех уровней вложенности.
- **Интерактивная «Лапа» (Pan Hand Tool):**
  - Плавное панорамирование чертежей любого масштаба мышью без рывков.
- **Мгновенный рендеринг документации:**
  - **PDF:** многоуровневая растеризация (миниатюры 72 DPI, обзорные листы 150 DPI, чистовой зум 300 DPI через PyMuPDF).
  - **DWG:** автономный рендеринг чертежей и пространств листов (Layouts) без обязательного запуска тяжелого AutoCAD.
  - **Excel / Word:** предварительный просмотр листов смет, ведомостей (ВОР) и договоров.

## Быстрый запуск

1. Запустить скрипт `Запуск_Лаунчера.cmd` (или бинарник `FEngineeringLauncher.exe`).
2. Окно программы откроется автоматически. Сервер работает локально по адресу `http://127.0.0.1:8780/`.
