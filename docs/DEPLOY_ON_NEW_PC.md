# Перенос и развёртывание Launcher на новый компьютер

В проекте реализовано два способа переноса на другой компьютер:
1. **Рекомендуемый (Быстрый, USB-версия «Всё включено»)** — 0 настроек, без прав администратора, без интернета, без установки Python.
2. **Для разработчиков (через Git)** — клонирование репозитория и ручная настройка окружения.

---

## Способ 1. Автономная USB-версия «Всё включено» (Рекомендуется)

Идеально подходит для переноса на компьютеры коллег, рабочие станции без прав администратора и компьютеры без интернета.

### Шаг 1. На компьютере-доноре (где всё работает)
1. Вставьте флешку в компьютер.
2. В корне проекта запустите:
   ```cmd
   Собрать_на_флешку.cmd
   ```
3. Укажите букву диска флешки (например, `E:`) или нажмите Enter для создания сборки в `C:\Codex\FEngineering_Launcher_Portable`.
4. Скрипт автоматически:
   - Соберёт чистый код приложения.
   - Упакует автономный Python с библиотеками (`PyMuPDF/fitz`, `openpyxl`, `pypdf`, `pywebview`).
   - Упакует портативный Poppler для рендеринга PDF.
   - Создаст запускалки `Запуск_Лаунчера.cmd` и `Создать_ярлык_на_Рабочем_столе.cmd`.
   - Создаст единый ZIP-архив `FEngineering_Launcher_v3_Portable.zip` (если захотите отправить по почте или через диск).

### Шаг 2. На компьютере-реципиенте (целевом ПК)
1. Вставьте флешку.
2. **Вариант А (самый быстрый)**: Скопируйте папку `FEngineering_Launcher_Portable` на диск `C:\` или `D:\`. Запустите `Создать_ярлык_на_Рабочем_столе.cmd` — на рабочем столе появится ярлык с иконкой.
3. **Вариант Б**: Запустите файл `Запуск_Лаунчера.cmd` прямо с флешки.
4. Лаунчер сразу открывается и готов к работе! Никаких консолей и настроек.

---

## Что со штатными программами (AutoCAD, Word, Excel)
- Если на целевом ПК установлен AutoCAD — чертежи DWG откроются в нём.
- Если на целевом ПК установлен Microsoft Office — таблицы XLS/XLSX и документы DOC/DOCX откроются в них.
- Если офиса или САПР нет — лаунчер всё равно полноценно отображает таблицы XLSX и чертежи (через их PDF-пары) во встроенном просмотрщике.

## Способ 2. Развёртывание из репозитория Git (Для разработчиков)

Если требуется разрабатывать лаунчер из исходников:

1. Клонировать репозиторий:
   ```powershell
   git clone <url-репозитория> FEngineering_Launcher_v3
   cd FEngineering_Launcher_v3
   ```
2. Установить Python 3.10+ (рекомендуется Python 3.14).
3. Установить зависимости:
   ```powershell
   pip install -r requirements.txt
   ```
4. Установить Poppler:
   ```powershell
   winget install -e --id oschwartz10612.Poppler
   ```
5. Запустить первичную настройку и проверку:
   ```cmd
   SETUP.cmd
   ```
6. Запускать через `Запуск_Лаунчера.cmd`.
