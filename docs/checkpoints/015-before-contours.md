## 1. Назначение контрольной точки

Данная контрольная точка фиксирует стабильное, подтверждённое пользователем состояние пользовательского интерфейса лаунчера `FProject-Launcher` перед началом этапа глубокой доработки геометрического ядра экспорта PDF $\rightarrow$ DWG.

Пользователь подтвердил корректную работу следующих функций:
1. Кнопка «Загрузить» (системный диалог выбора папки Windows, импорт объекта, корректная отмена).
2. Клавиша `Escape` (возврат из полноэкранного Окна 3 в Окно 2 и Окно 1 с сохранением контекста).
3. Верхняя панель действий `.action-grid` во 2-м окне (не исчезает при отображении PDF, все кнопки активны).
4. Локальное контекстное меню ПКМ внутри просмотрщика PDF:
   - «Скопировать» (извлечение текста из DOM-слоя `.textLayer` в буфер Windows `CF_UNICODETEXT`);
   - «Перевести» (перевод выделенного фрагмента);
   - «В DWG перевести» / «Экспорт в DWG» (запуск пайплайна генерации DWG/DXF и автооткрытие в нативном CAD-приложении через `/api/cad/open`).

> **Важно**: Подтверждение функционала интерфейса и вызова экспортёра НЕ является подтверждением качества CAD-геометрии. Качество получаемых профилей фиксируется в разделе «Известные ограничения» ниже и подлежит доработке в следующих заданиях.

## 4. Известные ограничения экспорта PDF → DWG (Задел для следующих этапов)

1. **Масштабирование и система координат**:
   - Исходные координаты извлекаются в типографских пунктах (pt, 1/72 дюйма).
   - Требуется строгая верификация масштабирующего множителя в мм (1 pt = 0.352778 мм, 1 мм = 2.834646 pt) и согласование с физическими габаритами профилей по образцовым размерам (напр. 77 мм и 167 мм на стр. 211 каталога Reynaers MasterLine 8).
2. **Засорение геометрии вспомогательными объектами**:
   - В итоговый DXF попадают элементы оформления: текстовые метки, размерные линии со стрелками, штриховки изоляторов, перекрывающие контуры основного металла.
3. **Топологическая незамкнутость контуров**:
   - Векторные пути в PDF состоят из независимых сплайнов и отрезков; на дугах скруглений и сопряжениях имеются разрывы порядка 0.05–0.76 мм.
   - Базовый алгоритм сшивки оставляет до 45% линий открытыми, не формируя валидные замкнутые полилинии (`LWPOLYLINE closed`).
4. **Неделимость составного профиля**:
   - Сечение термоизолированного профиля состоит из трех физических тел: внутренняя чаша (алюминий), наружная чаша (алюминий) и термомост (полиамид). В текущей реализации они не декомпозируются на раздельные замкнутые контуры / блоки / слои.
5. **Статус эталонных площадей**:
   - Значение 634.28 мм² является предварительным расчётом по прототипу для чаши рамы, но не утверждённым окончательным эталоном.
