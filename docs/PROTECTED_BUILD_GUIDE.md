# Регламент безопасной сборки и коммерческой дистрибуции лаунчера

> **Дата**: 2026-11-28  
> **Статус**: Production Standard / Инструмент защиты интеллектуальной собственности FERO  
> **Скрипт конвейера**: `scripts/build_protected_dist.py`

---

## 1. Задачи системы защиты
1. **Защита от копирования и разбора кода:**
   - Трансляция Python-кода ядра в машинный код C++ через компилятор Nuitka.
   - Очистка фронтенда (`app.js`) от комментариев и подготовка к обфускации.
   - Сборка в единый монолитный исполняемый файл `FeroLauncher.exe` без открытых исходников на диске.
2. **Ограничение срока ознакомительной версии (Kill-Switch):**
   - Вшитый настраиваемый срок действия (по умолчанию 30 дней со дня сборки).
   - Анти-чит контроль системного времени (защита от отката часов назад).
   - Вывод окна блокировки с контактами для продления при истечении срока.

---

## 2. Команды сборки защищенного дистрибутива

### 2.1. Быстрая подготовка триал-версии на 30 дней:
```bash
python scripts/build_protected_dist.py --trial-days 30
```

### 2.2. Сборка с точной датой окончания (например, до 15 февраля 2027 г.):
```bash
python scripts/build_protected_dist.py --expires 2027-02-15
```

Скрипт автоматически:
1. Создаст изолированный каталог `dist_protected/stage/`.
2. Встроит флаг `TRIAL_ENABLED = True` и дату окончания в модуль `license_guard.py`.
3. Очистит и сожмет `app.js` фронтенда.
4. Сформирует скрипт сборки `dist_protected/compile_nuitka.cmd`.

---

## 3. Финальная компиляция в C++ бинарник через Nuitka

Для запуска компилятора Nuitka дважды кликните по созданному файлу:
```
dist_protected\compile_nuitka.cmd
```

### Требования к окружению:
- Установленный Python 3.10+ (x64).
- Microsoft Visual C++ Build Tools (или компилятор MSVC из состава Visual Studio Community).
- Nuitka (`pip install nuitka ordered-set`).

### Результат сборки:
В папке `dist_protected/` появится единственный файл:
- **`FeroLauncher.exe`** (~45–60 МБ) — полностью автономный, скомпилированный в бинарный машинный код продукт.
- Исходный код Python внутри отсутствует.
- Исходный код JavaScript защищен внутри бинарника.
- При наступлении даты окончания программа прекращает работу без подтверждения разработчика.
