# Чекпоинт стабильной версии: FProject Launcher (2026-11-23)

> **Статус**: Стабильный базовый релиз (Verified Stable Baseline).
> **Ветка**: `main`
> **Исполняемый релиз**: `dist_release/F-Engineering_Launcher.exe` (99.57 МБ, SFX 7-Zip).

---

## 1. Зафиксированное рабочее состояние

1. **Отказ от функционала «Паспорт объекта»:**
   - Интерфейс и кодовая база полностью зачищены от кнопки «Паспорт объекта» и связанных с ней веток генерации отчетов.
   - Устранены синие визуальные артефакты в шапке, всплывающие окна и паразитные вызовы.

2. **Оптимизация интерфейса и окон просмотра:**
   - **Окно №2 (лента миниатюр):** убрано дублирующее меню управления (`.viewer-controls`), освобождено полезное пространство для скролла и обзора.
   - **Окно №3 (полноэкранный просмотр):** убрана лишняя кнопка ручного переключения DPI (`150/300`). Вся система переведена на гарантированное высокое качество (300 DPI по умолчанию с аппаратным авто-ограничением для видеокарт).
   - **Плавающая панель управления:** добавлена композитная изоляция (`isolation: isolate; contain: paint; backface-visibility: hidden;`). Меню не мерцает и не исчезает при зуме и панорамировании.

3. **Аппаратная стабилизация GPU для нестандартных и гигантских форматов:**
   - Внедрён модуль `compute_safe_raster_dpi()` в `dwg_engine.py` и `server.py`.
   - Для стандартных листов (А4, А3, А2, А1) рендеринг выполняется при полных **300 DPI**.
   - Для удлинённых форматов по ГОСТ 2.301-68 (например, развёртки фасадов А3×5 длиной 1.5 метра — вокзал Саратов) максимальный размер растра безопасно калибруется (не более 14 000 px по длинной стороне).
   - Исключено пробитие аппаратного лимита видеопамяти `MAX_TEXTURE_SIZE` (16 384 px), предотвращены сбросы контекста GPU и появление «белых пятен».

4. **Контекстное меню (ПКМ) для Word и Excel:**
   - Устранён конфликт `iframe blur`: пункты меню («Скопировать путь», «Открыть в проводнике», «Открыть в программе по умолчанию») срабатывают мгновенно по событию `pointerdown`.
   - Внедрён надёжный фоллбэк для извлечения путей файлов через `state.activeNativePath` и `state.revealedPath`.

5. **Тестирование и автономный дистрибутив:**
   - Проведено сквозное браузерное тестирование через Playwright (Excel, Word, DWG, PDF).
   - Собран автономный самораспаковывающийся дистрибутив `dist_release/F-Engineering_Launcher.exe`.

## 2. Стратегические направления развития (Куда двигаться дальше)

1. **Направление 1: Поиск и фильтрация в дереве проектов (Search & Deep Indexing):**
   - Мгновенный поиск по шифрам, номерам листов, маркам (АР, КМ, КЖ) и ключевым словам в длинных названиях файлов без задержек.
   - Фильтры по статусу готовности превью (отрендерен / в очереди).

2. **Направление 2: Интеллектуальное сопоставление DWG и PDF (Smart Pairing 2.0):**

   - Автоматическая группировка листов при многостраничных комплектах.

3. **Направление 3: Модули инженерной аналитики (Bounded Processing Modules):**
