# Спецификация быстрого экспорта тяжелых DWG (AutoCAD Headless Export Pipeline)
**Инженерное бюро ООО «ФЕРО»**  
*Статус: Принятый производственный стандарт (09 ноября 2026 г.)*

---

## 1. Проблема: Почему тяжелые DWG зависали при экспорте в PDF

При пакетном экспорте сложных многостраничных чертежей (30–50 МБ, 50+ листов КМ/КМД/АР) стандартный экспорт через `accoreconsole.exe` зависал на 15–16 листах (время рендеринга одного листа достигало **292 секунд / 5 минут**), после чего процесс аварийно прерывался по таймауту.

### Коренные причины ступора:
1. **Эпидемия комментариев SHX (`EPDFSHX = 1` по умолчанию в AutoCAD):**  
   Для каждого символа векторных шрифтов ГОСТ (SHX) плоттер `_.-EXPORT _PDF` создавал невидимый PDF-комментарий (Annotation). На сложных листах фасадов с 10 000+ символами создавалось более **11 000 аннотаций на один лист**! Это перегружало генератор PDF и вешало любой просмотрщик.
2. **Ловушка перезапуска процесса (Cold Boot Penalty):**  
   Запуск `accoreconsole.exe` отдельно для каждого листа приводил к повторной загрузке 37-МБ файла с диска в память (каждое открытие занимает **48.4 секунды**). Для 51 листа это давало **более 40 минут** чистого времени загрузки файла.
3. **Жёсткий статический таймаут:**  
   Лимит в 300 секунд на всю операцию убивал процесс, как только общий хронометраж превышал 5 минут.

## 2. Ключевые переменные окружения AutoCAD (Рецепт скорости)

При формировании скриптов AutoLISP для `accoreconsole.exe` **обязательна** следующая связка системных переменных:

```lisp
(setvar "EXPERT" 5)          ; Подавление всех диалоговых вопросов (типа "Заменить файл?", "Сохранить?")
(setvar "FILEDIA" 0)         ; Полное отключение файловых диалогов Windows
(setvar "CMDDIA" 0)          ; Полное отключение диалогов команд AutoCAD
(setvar "BACKGROUNDPLOT" 0)  ; Синхронная печать в основном потоке (без фоновых гонок процессов)
(setvar "EPDFSHX" 0)         ; КРИТИЧЕСКИ ВАЖНО: Отключение генерации паразитных PDF-аннотаций для шрифтов SHX!
```

### Почему `EPDFSHX = 0` критичен:
* `EPDFSHX = 1` (по умолчанию): превращает каждую букву ГОСТ в PDF-комментарий, раздувает файл и тратит до 70% времени рендера на запись служебных объектов PDF.
* `EPDFSHX = 0`: чертит буквы как чистую векторную геометрию, сокращая время генерации листа **в 2.5–3.5 раза**.

## 3. Архитектура Single-Pass Progressive Export

1. **Однократная загрузка файла в RAM (Single-Pass):**  
   Файл открывается в `accoreconsole` **один раз** (48 секунд холодной загрузки тратятся один раз на весь файл).
2. **Мгновенный реестр вкладок:**  
   Скрипт за первые 200 мс опрашивает словарь `(dictsearch (namedobjdict) "ACAD_LAYOUT")`, находит все заполненные листы (`ssget "_X" '((410 . lname))' > 1`) и сохраняет `layouts.txt`. Лаунчер мгновенно строит оглавление для инженера.
3. **Последовательный экспорт:**  
   Внутри одного процесса AutoCAD цикл переключает вкладки `(setvar "CTAB" lname)` и выполняет экспорт каждого листа:
   ```lisp
   (command "_.-EXPORT" "_PDF" "_C" "_N" outpdf)
   ```
4. **Скользящий таймаут активности (Sliding Idle Timeout):**  
   Вместо фиксированных 300 секунд на весь файл лаунчер отслеживает активность:
   - Если за последние 300 секунд появился хотя бы один новый готовый лист — таймер сбрасывается.
   - Процесс принудительно завершается только при реальном глухом зависании (> 300 сек без новых страниц) или при общем потолке 3600 сек (1 час для файлов 100+ листов).
5. **Векторно-растровый конвейер PyMuPDF (150 DPI):**  
   Готовый векторный `page_NNNN.pdf` растеризуется через PyMuPDF (`fitz`) за **3–4 секунды** в чёткий растр `3509 × 2482 px` (размер листа А2). Все штампы, примечания и размеры остаются резкими и читаемыми.
