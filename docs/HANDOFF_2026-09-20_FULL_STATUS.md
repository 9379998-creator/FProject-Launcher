## 1. Что такое Launcher

F-Engineering Launcher v3 — локальное Windows-приложение (без облака) для инженеров:
открывает папку объекта → дерево файлов (окно 1) → лента миниатюр (окно 2) →
большой просмотр (окно 3). Форматы: PDF, Excel (XLS/XLSX/XLSM/CSV через HTML),
Word (через PDF), картинки (JPG/PNG/TIF/GIF…), TXT, DWG (через PDF-пару или
рендер AutoCAD COM), остальное — нативные карточки. Бэкенд — Python HTTP
(`app/backend/server.py`, порт `8780`), фронт — чистый JS (`app/frontend/app.js`,
~4500 строк), без сборщиков и Node-зависимостей (`requirements.txt`: openpyxl,
pymupdf, pypdf, pywebview).

## 6. Последняя проблематика: окно AutoCAD слева вверху + мигание

- Пользователь открывает DWG через **ассоциацию ОС** (`mode: system-default`),
  где окно ищет 120-секундный сторож по имени файла без центрирования и долбит
  фокус каждые 2 с — отсюда мигание; первый патч стоял на пути custom-exe,
  которым пользователь не пользуется, плюс запускалась старая папка без патча.
- Внесено (не закоммичено): общий `_center_window_on_screen` (центр без смены
  размера/фокуса, мимо развёрнутых) + центрирование в обоих сторожах + стоп
  после 6 неудач фокуса (~12 с вместо 120 с мигания). Диагностика пишется в
  `runtime/logs/native-front.log` (`centered-before/after`).
- Для проверки: закрыть старый сервер, запустить
  `..._CURRENT_COPY\scripts\start_windows.cmd`, открыть DWG, смотреть окно и
  хвост `native-front.log`. В момент записи пользователь ещё на старой папке.
