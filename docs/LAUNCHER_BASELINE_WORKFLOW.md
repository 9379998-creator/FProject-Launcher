# Базовый workflow лаунчера (freeze 2026-09-17)

Каркас поведения. Проверен вручную пользователем. Меняется только явным решением пользователя.

## Поток

1. Запуск лаунчера.
2. Окно 1: список объектов.
3. «Загрузить» → нативное окно выбора папки → импорт объекта.
4. Выбор объекта → дерево файлов (Окно 2).
5. Поиск / фильтры / выбор одного или нескольких файлов.
6. «Отобразить» → лента миниатюр + большой просмотр (Окно 3).
7. Перемещение по миниатюрам, синхронизированным с деревом.
8. Большой режим для подробного просмотра.
9. Возврат по Escape / «Назад» к ленте, дереву или списку объектов.
10. При необходимости: открыть в нативной программе, показать в Проводнике, копировать путь.

## Три зоны

- Окно 1 — список объектов (`#objectListState`): объекты, статистика, выбор.
- Окно 2 — дерево файлов (`#treeState`, `#objectTree`): поиск (`#treeSearch`), фильтры форматов (`#formatStrip`).
- Окно 3 — лента миниатюр (`#pdfThumbs`) + большой просмотр (`#pdfStage`): масштаб, вращение, страницы/листы, режимы просмотра.

## Кнопки

- Загрузить — импорт папки (контракт: `docs/LOAD_BUTTON_CONTRACT.md`).
- Обновить — повторный скан объекта, дифф добавленных/изменённых/удаленных без потери контекста.
- Отобразить — открыть объект: дерево + лента + просмотр.
- Исключить — убрать объект из списка (папка на диске не трогается).
- Объекты / Назад — возврат между списком, деревом и предыдущим узлом.
- Параметры — ассоциации программ для нативного открытия.
- Масштаб (− / 100% / +) — дерево и миниатюры.

## Действия

- Один клик — выбор; двойной клик — открыть; правый клик — контекстное меню (открыть, показать в Проводнике, копировать путь); Escape — шаг назад.
- Синхронизация: дерево ↔ миниатюра ↔ большой просмотр всегда согласованы.

## Нативные операции

- Открыть в программе (`POST /api/open-file`, action `native`/`system`).
- Показать в Проводнике (`POST /api/open-file`, action `explorer`).
- Копировать путь (`POST /api/clipboard` с браузерным fallback).
