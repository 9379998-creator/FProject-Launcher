## 2. Среда запуска и зависимости

### Команда запуска приложения
Launcher запускается на локальном HTTP-сервере с WebView2-оболочкой:
```powershell
# Запуск бэкенда:
python app/backend/server.py --port 8780

# Запуск десктопной оболочки WebView2:
python launcher_app.py
```

### Зависимости окружения
- **Python**: 3.14.x (Windows AMD64)
- **Основные библиотеки** (`requirements.txt`):
  - `pymupdf==1.27.2.3` (рендеринг PDF страниц высокого разрешения)
  - `pypdf==6.12.2` (пакетный анализ и манипуляции с PDF)
  - `pywebview==6.2.1` (десктопное окно Microsoft Edge WebView2)
  - `Pillow==12.2.0` (обработка растровых превью)
  - `python-docx==1.2.0` (чтение Word)
  - `openpyxl==3.1.5` и `xlrd==2.0.2` (чтение Excel)
- **Установка зависимостей**:
  ```powershell
  python -m pip install -r requirements.txt
  ```

### Сведения о сборке Frontend
- **Frontend не требует сборщика** (Node.js/Vite/Webpack не используются в рантайме).
- Файлы `app/frontend/index.html`, `app/frontend/styles.css` и `app/frontend/app.js` отдаются бэкендом напрямую как статические ресурсы (`serve_static` с заголовками `Cache-Control: no-cache, no-store, must-revalidate`).
- Запущенный процесс использует текущие исходники напрямую из файловой системы.

## 5. Правила дальнейшей разработки

1. **PDF — принят как эталон текущего пользовательского поведения**:
   - Логика масштабирования, панорамирования, рендеринга страниц и навигации по PDF объявляется **замороженной** и неизменяемой без явного согласования владельца.
   - Любые изменения общих компонентов интерфейса (дерево, лента миниатюр, обработчики мыши/клавиатуры) требуют обязательной проверки на отсутствие регрессий в PDF.

2. **Следующие этапы работ**:
   - Чертежи DWG;
   - Электронные таблицы Excel;
   - Текстовые документы Word;
   - Изображения.

3. **Целевая схема обработки DWG**:
   - Определение полного списка пространств листов (Layouts) AutoCAD.
   - Рендеринг каждого листа в отдельный PDF.
   - Валидация полноты комплекта (все ожидаемые листы сформированы).
   - Сохранение исходного проектного порядка листов.
   - Объединение в полный PDF-комплект документа.
   - Открытие комплекта через **принятый эталонный PDF-просмотрщик**.
   - Запрет на создание параллельных/альтернативных реализаций zoom/pan/fit под DWG.
   - Запрет на публикацию неполных комплектов под видом успешных.
   - Запрет на использование устаревших страниц кэша при изменении исходного DWG файла.
   - При сбое генерации — сохранение предыдущей успешной версии с отображением точной причины ошибки.
