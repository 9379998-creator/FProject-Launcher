# Чекпоинт: Фиксация архитектуры Viewer-Only, эстетика Apple Minimalist и геометрия интерфейса

> **Дата**: 2026-11-28  
> **Версия лаунчера**: 4.6.0  
> **Статус**: Production Ready / Согласовано и утверждено Заказчиком  
> **Репозиторий Git**: `https://github.com/9379998-creator/Fero-Launcher`  
> **Ветки архитектурного разделения**:
> - `main`: Канонический быстрый просмотрщик чертежей и документов (*Visual Triage & Document Viewer only*).
> - `fera-analytic`: Автономный инженерно-аналитический модуль (Netto BoQ, 5-уровневый коллизионный аудит, генерация паспортов объектов и смет).

## 1. Разделение ответственности и изоляция аналитики (Viewer-only vs Standalone FERA Analytic)

### 1.1. Регламент ветки `main` (Visual Triage & Viewer Only)
1. **Единственное назначение:**
   - Мгновенное открытие и просмотр папок объектов любой сложности (включая многотомный архив ОД150).
   - Построение дерева файлов с фильтрацией по форматам (PDF, DWG, Word, Excel, изображения).
   - Высокоскоростной двухступенчатый рендеринг: превью ленты 150 DPI, активный чертёж 300 DPI.
   - Быстрый запуск оригинальных файлов в нативных инженерных программах (AutoCAD, Word, Excel, Acrobat).
2. **Полный запрет на расчетные модули в ветке `main`:**
   - Ветка `main` полностью очищена от кнопок аудитов, анализа штампов и генераторов ВОР/смет.
   - Вся расчетная логика исключена из серверного демона `server.py` и клиентского интерфейса `index.html`.

### 1.2. Вынос аналитики в ветку `fera-analytic`
- Для инженерно-экономических расчетов сформирована выделенная ветка `fera-analytic` (коммит `e9337d6`).
- Реализована автономная микроутилита `fera_analytic/` с собственным независимым GUI в стиле Apple Minimalist (`fera_analytic/app.pyw`, запуск через `FERA_Analytic.cmd`).
- Расчетный движок `fera_analytic/engine.py` производит:
  - Прямой аудит штампов и форматов чертежей через PyMuPDF (`fitz`).
  - 5-уровневый коллизионный аудит документации (планы vs фасады, ведомости vs чертежи).
  - Формирование интерактивного Apple Minimalist паспорта объекта (`ПАСПОРТ_ОБЪЕКТА.html`) и брендированной сметы Excel (`РАСЧЕТ_ОБЪЕМОВ.xlsx`).

## 2. Редизайн верхней панели действий (Top Action Bar Contract)

### 2.1. Исключение неиспользуемых элементов и переименование
- **Удаление процентного масштабирования:** Виджет кнопок процентного шага (`#scaleWidget`) полностью удален. Масштабирование осуществляется нативно колесом мыши с зажатым Ctrl, ползунком и кнопкой «Вписать».
- **Удаление мертвой кнопки «Назад»:** Кнопка `#backToTree` удалена из верхнего бара. Возврат из полноэкранного режима Окна 3 осуществляется клавишей `Escape` и встроенной кнопкой заголовка `#viewBackBtn`.
- **Переименование «Отобразить» ➔ «Рендер»:** Кнопка `#displayObject` получила точное инженерное наименование «Рендер», соответствующее генерации растровых миниатюр из исходных PDF/DWG.

### 2.2. Фиксированная геометрия 6 кнопок (Strict 6-Button Grid)
Верхняя панель зафиксирована в составе ровно 6 кнопок:
```
[ Объекты ]   [ Загрузить ]   [ Обновить ]   [ Рендер ]   [ Параметры ]   [ Исключить ]
```
- **Ширина кнопок:** строго одинаковая `96 px` для всех 6 кнопок (`width: 96px; min-width: 96px; max-width: 96px;`).
- **Высота кнопок:** `28 px` (`height: 28px; line-height: 28px;`).
- **Межкнопочный интервал (Gap):** строго одинаковый шаг `8 px` между всеми кнопками (`gap: 8px; margin: 0 !important;`). Устранен обособленный отступ `margin-left: 6px` у кнопки «Параметры».

### 2.3. Эстетика Apple Minimalist и тактильный отклик (Tactile Push Feel)
- **Цветовая палитра:** подложка в покое — мягкий пастельный светло-серый тон `#EFEFF2` (без резкого белого контраста).
- **Скругление:** Apple squircle с радиусом `7 px` (`border-radius: 7px`).
- **Объем и контур:** тончайшая окантовка `1px solid #D1D1D6`, деликатная нижняя тень `box-shadow: 0 1px 2px rgba(0,0,0,0.06), 0 1px 0 rgba(255,255,255,0.7) inset`.
- **Интерактивные состояния:**
  - `:hover` — плавное осветление до `#F5F5F8`.
  - `:active` — упругое нажатие с физическим микросдвигом `transform: translateY(1px)`, подложка `#E2E2E7`, внутренняя тень `box-shadow: inset 0 1px 2px rgba(0,0,0,0.12)`.
- **Устранение рамки фокуса:** добавлено жесткое правило `outline: none !important;` в CSS и программный сброс фокуса (`blur()`) при старте приложения, что полностью устранило появление толстой синей/черной рамки фокуса вокруг кнопки «Загрузить».

## 3. Геометрия скруглений окон и элементов (Zones 1, 2, 3)

### 3.1. Окно 1 (Левый сайдбар / Zone 1)
Для гармонии с закругленными кнопками верхнего меню прямоугольные элементы сайдбара получили мягкие радиусы скругления:
- Поле быстрого поиска по дереву (`#treeSearch`): `border-radius: 8px`.
- Фильтры форматов чертежей (`.format-chip`): `border-radius: 6px`.
- Карточки объектов в реестре (`.object-item`): `border-radius: 7px`.
- Строки и папки дерева файлов (`.tree-item`): `border-radius: 6px`.
- Контейнеры списков, блоки статистики и прогресс-бар: `border-radius: 8px`.

### 3.2. Окно 2 (Центральная лента миниатюр / Zone 2)
- Карточки чертежей (`.pdf-thumb`): внешний радиус `border-radius: 8px`.
- Внутренние растровые изображения страниц: `border-radius: 5px` (плавное сопряжение без вылезания углов за пределы карточки).

### 3.3. Окно 3 (Сцена / Холст детального просмотра / Zone 3) — ПРЯМОУГОЛЬНЫЙ СТАТУС-КВО
- **Полный запрет на скругления холста:** Окно 3 (`#pdfStage`, `#pdfCanvas`, `.page-wrapper`, `#excelViewer`, оверлеи Word/DWG) остается **строго прямоугольным**.
- Инженерные чертежи, спецификации и таблицы отображаются с миллиметровой строгостью без обрезки краев, штампов или координационных осей.

## 4. Симметрия разделителя между Окном 1 и Окном 2

### 4.1. Проблема визуальной асимметрии
При рендеринге чертежей правая белая рамка ленты миниатюр Окна 2 визуально казалась шире левой серой рамки Окна 1 из-за избыточных внешних отступов контейнера миниатюр (`padding: 12px 18px;` и центрирования `margin: 0 auto;`).

### 4.2. Калибровка равных зазоров (Strict 6 px Symmetry)
Внутренние отступы согласованы до миллиметра:
- **Слева от сплиттера (Окно 1):** серый отступ строго `6 px` (`.sidebar { padding: 5px 6px 6px 6px; }`).
- **Справа от сплиттера (Окно 2):** белый отступ строго `6 px` (`.pdf-thumbs { padding: 5px 6px 6px 6px; }`, `.thumb-wrap { width: 100%; margin: 0 0 10px; }`).
- Границы контента с обеих сторон от вертикального разделителя абсолютно симметричны.
