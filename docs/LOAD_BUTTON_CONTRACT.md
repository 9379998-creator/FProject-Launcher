# Контракт кнопки «Загрузить» (обновлено 2026-11-03 по прямому указанию пользователя)

Заморожен. Меняется только явной командой пользователя.

## Единственная допустимая цепочка

Загрузить → `triggerSystemPicker` → `POST /api/choose-folder` → нативный современный проводник Windows (`folder_picker.exe` / `IFileOpenDialog` с `FOS_PICKFOLDERS` и живой адресной строкой) → JSON `{ "path": "..." }` → `importObjectByPath` → импорт объекта.

- Один клик — одно нативное окно современного проводника с адресной строкой (поддержка ввода сетевых путей `\SERVER\...` и дисков `Z:\`).
- Отмена — тихий выход без импорта и без ошибки (код возврата 1).
- Повторные клики не плодят диалоги (`isPickerOpen` + блокировка кнопки, сброс в `finally`).

## Запрещено

- Добавлять `startProgress` / `finishProgress`, проценты, таймеры, панели прогресса в `triggerSystemPicker`.
- Создавать HTML/WebView/самописный файловый браузер вместо системного диалога.
- Возвращать из `/api/choose-folder` что-либо кроме JSON (`{ "path" }` / `{ "path": "", "error" }`).
- Добавлять промежуточные скрипты, COM-обвязки, tkinter-fallback, «улучшенные» диалоги без явной команды пользователя.
- Удалять `isPickerOpen` и блокировку кнопки на время диалога.
- Оживлять удалённое: `scripts/choose_folder.*`, `GET /api/browse`, `browse_filesystem()` и подобные механизмы.

## Живой тест перед изменениями

Один клик → одно окно → выбор → импорт; отмена → тихий выход, кнопка разблокирована. Без этого теста не коммитить.
