## 1. Проблематика и разбор инцидента при обновлении лаунчера

### 1.1. Симптоматика инцидента
При попытке обновления пользователями до версии 4.5.0 через автономный исполняемый файл возникли две связанные проблемы:
1. **Иллюзия отсутствия обновления:**
   Пользователь запускал скачанный файл `Fero_Launcher_v4.5.0.exe`, однако при последующем открытии программы с Рабочего стола продолжала запускаться старая версия 4.0 со старым микросхемным значком и устаревшей карточкой-листочком в Окне 3.
2. **Предупреждение при установке:**
   При развертывании пакета в самом конце процесса (на 100% шкалы) появлялось модальное системное предупреждение:
   *«Невозможно выполнить файл: ... ie4uinit.exe»*.

---

### 1.2. Анализ первопричин (Root Cause Analysis)

1. **Временный SFX-архив вместо установщика:**
   - Предыдущий сценарий сборки использовал 7-Zip SFX модуль (`7z.sfx`), распаковывающий дистрибутив во временный каталог операционной системы `%TEMP%\7zXXXX.tmp`.
   - Временный архив физически не копировал обновлённые файлы в рабочую папку пользователя `%LOCALAPPDATA%\FEngineering_Launcher`, не перенаправлял ярлыки и удалялся после завершения сессии. В результате ярлык на Рабочем столе продолжал запускать нетронутую старую версию.
   - Запущенный ранее фоновый процесс сервера `server.py` оставался в памяти на порту `8780`, возвращая клиенту закэшированный старый интерфейс.

2. **32-битная переадресация Windows и отсутствующая утилита в SysWOW64:**
   - Для мгновенного сброса кэша иконок на Рабочем столе инсталлятор в секции `[Run]` вызывал системную команду `{sys}\ie4uinit.exe -show`.
   - При сборке инсталлятора без директивы `ArchitecturesInstallIn64BitMode=x64` процесс работал в 32-битном режиме совместимости, из-за чего `{sys}` транслировался в каталог `C:\Windows\SysWOW64\ie4uinit.exe`.
   - В современных 64-битных ОС Windows 10/11 в папке `SysWOW64` файл `ie4uinit.exe` отсутствует (он расположен исключительно в нативной папке `C:\Windows\System32`).
   - Отсутствие флага `skipifdoesntexist` приводило к тому, что Inno Setup воспринимал отсутствие необязательного вспомогательного файла как ошибку и выводил всплывающее диалоговое окно в самом конце установки.

## 2. Реализованный архитектурный стандарт бесшовного обновления (In-place Upgrade)

### 2.1. Полноценный инсталлятор на базе Inno Setup 6
Вместо SFX-архива сформирован специализированный скрипт `installer/launcher_upgrade.iss`:
- **Целевая директория по умолчанию:** строго `{localappdata}\FEngineering_Launcher` (точный рабочий каталог, где уже развернут лаунчер).
- **Права доступа:** `PrivilegesRequired=lowest` — установка происходит исключительно в профиль пользователя, исключая блокировки прав администратора (*UAC prompts*).
- **Режим наката «поверх»:** флаги `ignoreversion recursesubdirs createallsubdirs` обеспечивают замену только программных исполняемых файлов, ядра, интерфейса и стилей.

### 2.2. Гарантия непрерывности пользовательских данных (Data Continuity)
Категорически исключены из перезаписи каталоги пользовательских данных:
```ini
Excludes: "runtime\manifests\*,runtime\db\*,runtime\logs\*,runtime\cache\*"
```
- **Манифесты объектов (`runtime\manifests`):** все ранее добавленные проекты и чертежи пользователей гарантированно сохраняются. Ни один объект не слетает.
- **База данных (`runtime\db\launcher.sqlite`):** история и метаданные остаются нетронутыми.
- **Пользовательские ассоциации (`native_apps.json`):** настройки открытия файлов в сторонних программах сохраняются.

### 2.3. Автоматическое снятие блокировок процессов
Перед началом копирования файлов в коде инсталлятора выполняется процедура принудительного снятия файловых блокировок:
```pascal
Exec('taskkill.exe', '/F /IM FEngineeringLauncher.exe', '', SW_HIDE, ewWaitUntilTerminated, ErrorCode);
Sleep(800);
```
Это гарантирует выгрузку как графической оболочки, так и дочернего сервера на порту `8780`, снимая блокировку с исполняемых файлов `FEngineeringLauncher.exe` и `server.py`.

### 2.4. Прямой вызов нативного API Windows для обновления иконок (SHChangeNotify)
Вместо ненадежного вызова сторонних `.exe` утилит внедрена прямая интеграция с Windows Shell API:
```pascal
procedure SHChangeNotify(wEventId: Longint; uFlags: Cardinal; dwItem1, dwItem2: Cardinal);
  external 'SHChangeNotify@shell32.dll stdcall';

procedure CurStepChanged(CurStep: TSetupStep);
begin
  if CurStep = ssPostInstall then
  begin
    try
      // SHCNE_ASSOCCHANGED ($08000000): сброс кэша иконок и обновление рабочего стола
      SHChangeNotify($08000000, 0, 0, 0);
    except
    end;
  end;
end;
```
Функция выполняется напрямую в памяти операционной системы, моментально обновляя значки на Рабочем столе и не вызывая никаких всплывающих диалоговых окон.

## 3. Редизайн стартового экрана Окна 3 (Zero-Scroll Flat Welcome Screen)

В соответствии со стандартом **Apple Minimalist**:
1. **Полный демонтаж старой карточки-листочка:**
   - Удалены стили `.welcome-card` (серые плашки, скругления, границы, псевдо-бумажные рамки и тени).
   - Внедрен открытый плоский контейнер `.welcome-flat-container`.
2. **Удаление устаревшей символики:**
   - Полностью вырезана векторная SVG-иконка микросхемы/паучка с оранжевой F.
   - Удалены файлы `flauncher_blue.ico` и `flauncher_blue.png` из репозитория.
3. **Вертикальная подтяжка и Zero-Scroll:**
   - Отступ сверху снижен до минимальных 14px (`align-items: flex-start`).
   - Сформирована компактная 2-колоночная сетка элементов управления:
     1. **Загрузить** — выбор папки через системный проводник Windows.
     2. **Отобразить** — раскрытие структуры объекта (дерево папок + лента миниатюр).
     3. **Обновить** — дифференциальный контроль изменений на диске.
     4. **Объекты** — возврат к общему реестру проектов.
     5. **Назад** — переход к предыдущему состоянию дерева.
     6. **Параметры** — привязка внешних CAD/Office программ.
     7. **Исключить** — удаление проекта из лаунчера без удаления файлов на диске.
     8. *Клавиша Escape и масштаб — универсальный возврат и зумирование.*
   - За счет компактной благородной типографики (`11.5px` заголовок, `10.5px` описание) все элементы помещаются на одном экране без необходимости вертикальной прокрутки.
